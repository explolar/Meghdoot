# MEGHDOOT — public site

Static landing page for **SIH26077**, *AI-Driven Hyper-Local Early Warning
System for Severe Weather Nowcasting* (Smart India Hackathon 2026, Team
AgriFlumes).

This is the public shell: what the project is, what it deliberately does not
claim, and where the code and the research live. The map and the forecast
layers arrive with the product stage.

## Deploy

No build step — a single `index.html`.

```
vercel deploy --prod
```

## Files

| Path | What it is |
|---|---|
| `index.html` | the whole site |
